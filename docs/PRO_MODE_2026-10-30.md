# Pro Mode

The owner approved option 2 of the desktop Today redesign and authorized
production publication. Added Pro Mode to Settings → Appearance → Skins.
It is an optional device preference using the existing skin picker/storage;
existing selected skins are preserved.

At 880px and above, Today uses separate score, wide Next Level and Log cards,
a large centered score ring without a heading, matched card borders and gutters,
consistent Habits/Bonus/Social typography and a full-width Day Note. At 1180px,
the existing navigation becomes a sidebar with a Settings control. Active
routine controls remain in the rightmost hero card. Below 880px, Pro Mode
preserves Original mobile geometry. Historical editors retain their layout.

Changes are limited to appearance, the skin registry, a hidden-unless-Pro
navigation control and versioned stylesheet inclusion. No new scoring rules,
backend changes, Auth changes, data migrations or account-data writes.
The implementation starts from production 783b6b5 and retains the current
Day Log, confirmed Reset, Wake/Sleep compatibility and tutorial changes.

Validation: 210 regression tests and 27 browser tests passed. After final
header/sidebar polish, the three targeted Pro Mode tests passed again.
Coverage includes widths 320–1920, identical mobile geometry, equal heading
and item typography, zero horizontal overflow, switching skins without
replacing unsaved notes or writing account data, persisted skin selection,
Work/routine credit, routine modal/orb and Log navigation, other tabs,
strict CSP/style protections, grade contrast and the nine-step tutorial.
All browser data are synthetic and requests are intercepted; real user
activity was not modified. Physical iPhone and Safari were not tested.

Evidence: pro-mode/desktop-synthetic.png, regression.log, browser.log,
layout-final.log. Build versions Pro Mode CSS with SHA-256 cache busting
and SHA-384 SRI alongside the existing production assets.
